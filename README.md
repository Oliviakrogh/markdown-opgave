# Markdown Dokumentation

## Liste over fordele ved markdown
*  Det er hurtigere at skrive end formateret tekst
*  Letlæseligt, også uden formatering
*  Gør det nemt at organisere indhold

## Kodeeksempel på javascript array forEach:

```
 
const fruits = 
["apple", "pineapple", "orange", "apricot"];

fruits.forEach(fruits)
console.log(fruits);

```
